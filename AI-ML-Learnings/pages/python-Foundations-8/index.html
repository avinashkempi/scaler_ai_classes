Sets, Tuples, Dictionaries

A card-by-card walkthrough to lock in tuples, sets, dictionaries, nested collections, and the decision process for choosing the right data structure.

🔮 predict before revealing 💬 debrief 🤖 AI moment ✅ takeaway

What this post-read covers

Tuples and immutability; tuple operations and unpacking; sets, uniqueness, membership and set operations; dictionaries and core methods; iteration; nested collections; common pitfalls; choosing the right data structure; and a cumulative word-frequency mini project.

01 · the idea

Why Do We Need More Than Lists?

Lists are flexible, but that flexibility is not always what we want. Sometimes data should stay fixed, sometimes duplicates should disappear, and sometimes we want to look something up by a meaningful name instead of a position.

Analogy — three jobs Think of a tuple as a sealed record, a set as a unique-items basket, and a dictionary as a labelled lookup book.
✅ Takeaway The goal is not to memorize three syntaxes. Match the data structure to the job the program needs to perform.
02 · tuples

A Tuple Is a Fixed Collection

A tuple looks like a list, but it uses parentheses and cannot be changed after it is created.

point = (3, 4)
print(point)
print(point[0])

(3, 4)
3
🔮 What do you think point[0] gives us?

3. Indexing and slicing work the same way as lists. The important difference is that a tuple cannot be modified.

📌 Instructor note The difference is not how you read a tuple. The difference is whether you can change it.
03 · tuples

The Comma Creates the Tuple

Parentheses are not what make a tuple. The comma is.

point = 3, 4
print(point)
print(type(point))

(3, 4)
<class 'tuple'>
🔮 Does this create an error, or a tuple?

It creates a tuple. The parentheses are mainly for readability here.

✅ Takeaway Remember: (3, 4) is a tuple, but the comma is what makes it a tuple.
04 · tuples

The Single-Element Trap

x = (5)
y = (5,)

print(type(x))
print(type(y))

<class 'int'>
<class 'tuple'>
🔮 Are both variables tuples?

No. (5) is simply the integer 5 inside parentheses. (5,) is the one-element tuple.

📌 Common pitfall A missing trailing comma does not produce an error — it produces a different data type.
05 · tuple operations

Indexing, Slicing, and Unpacking

coords = (10, 20, 30, 40)

print(coords[0])
print(coords[1:3])
print(coords[-1])

point = (3, 4)
x, y = point
print(x)
print(y)

10
(20, 30)

3
4
🔮 What values will x and y receive?

x = 3 and y = 4. Python matches each variable to the corresponding position in the tuple.

✅ Takeaway Tuples support indexing, slicing, and unpacking just like other ordered collections.
06 · tuple methods

Why Are There Only Two Main Tuple Methods?

coords = (10, 20, 10, 30, 10)

print(coords.count(10))
print(coords.index(30))

3
3

count() tells you how many times a value occurs. index() gives the first position where the value appears.

Analogy — a sealed record A tuple cannot be changed, so methods such as append(), remove(), and sort() do not belong to its toolkit.
07 · immutability

Trying to Change a Tuple

coords = (10, 20, 30)
coords[0] = 99

TypeError: 'tuple' object does not support item assignment
🔮 Will the first value change?

No. Python raises a TypeError because tuple elements cannot be reassigned.

✅ Takeaway Immutable means the object cannot be changed after it is created.

09 · sets

A Set Keeps Items Unique

numbers = {1, 2, 2, 3, 3, 3}

print(numbers)
print(len(numbers))

{1, 2, 3}
3
🔮 Six values were typed. How many elements remain?

3. Duplicate values are automatically collapsed.

Analogy — a guest list If the same person's name is added three times, a set still keeps only one copy of that name.
10 · sets

The Empty-Set Trap

empty = {}
print(type(empty))

empty_set = set()
print(type(empty_set))

<class 'dict'>
<class 'set'>
🔮 What are the two types?

{} creates an empty dictionary. Use set() to create an empty set.

📌 Common pitfall Curly braces are shared by set and dictionary syntax, so the empty case is special.
11 · set operations

Union, Intersection, Difference

python_students = {"Asha", "Rahul", "Priya"}
sql_students = {"Rahul", "Priya", "Karan"}

print(python_students | sql_students)
print(python_students & sql_students)
print(python_students - sql_students)
print(python_students ^ sql_students)
OperatorMeaning
|Union — everything from both sets
&Intersection — common elements
-Difference — elements only in the first set
^Symmetric difference — elements in exactly one set
🔮 Which students are common to both sets?

Rahul and Priya.

12 · sets

Membership and Set Methods

fruits = {"apple", "banana"}

print("apple" in fruits)
print("mango" in fruits)

fruits.add("cherry")
fruits.discard("mango")

print(fruits)
🔮 What happens when discard() receives a missing item?

Nothing. Unlike remove(), discard() does not raise a KeyError when the item is absent.

✅ Takeaway Sets are especially useful when the program needs uniqueness and membership testing.
13 · sets

Set Order Is Not the Point

Sets do not provide the same ordered-sequence guarantee as lists and tuples. Do not write logic that depends on the order in which a set happens to print or iterate.

fruits = {"apple", "banana", "cherry"}

for fruit in fruits:
    print(fruit)
📌 Remember If order matters, a set is usually the wrong structure. Use a list or tuple when sequence order is part of the requirement.
14 · dictionaries

Dictionary = Key → Value Lookup

student = {
    "name": "Asha",
    "age": 20,
    "course": "DSML"
}

print(student["name"])
print(student["age"])

Asha
20
🔮 What does student["name"] look up?

The value associated with the key "name": Asha.

Analogy — labelled drawers A list says “give me item at position 2.” A dictionary says “give me the value stored under this label.”
15 · dictionaries

Adding and Updating Keys

student["age"] = 21
student["grade"] = "A"

print(student)
🔮 Which line updates and which line adds?

student["age"] = 21 updates an existing key. student["grade"] = "A" adds a new key.

16 · dictionaries

get() vs Square Brackets

student = {"name": "Asha", "age": 20}

print(student.get("age"))
print(student.get("grade"))
print(student.get("grade", "Not Assigned"))

20
None
Not Assigned
✅ Takeaway Use get() when a key may be missing and you want a safe lookup instead of a KeyError.

🔮 Which method should you use when you need both key and value?

items().

18 · dictionary methods

update() and pop()

student.update({"age": 22, "grade": "A"})

removed = student.pop("grade")

print(removed)
print(student)
🔮 What does removed contain?

The value that was stored under "grade". pop() removes the key and returns its value.

19 · dictionaries

The Silent Key Overwrite

scores = {}
scores["Asha"] = 90
scores["Rahul"] = 85
scores["Asha"] = 95

print(scores)
print(len(scores))

{'Asha': 95, 'Rahul': 85}
2
🔮 Will there be 2 entries or 3?

There are 2 keys. The second assignment to "Asha" replaces 90 with 95.

📌 Common pitfall Dictionary keys are unique. Reusing a key updates the existing value rather than creating another entry.

21 · nested collections

Collections Inside Collections

scores = {
    "Asha": [90, 85, 95],
    "Rahul": [70, 75, 80]
}

print(scores["Asha"])
print(scores["Asha"][0])

[90, 85, 95]
90
🔮 What does the second [0] access?

The first element of Asha's list of scores.

✅ Takeaway When collections are nested, read the access from outside to inside: dictionary key first, then list/tuple index.
22 · nested collections

Dictionary of Dictionaries and List of Tuples

contacts = {
    "Asha": {"phone": "9999999999", "city": "Bengaluru"}
}
print(contacts["Asha"]["city"])

points = [(0, 0), (1, 2), (3, 4)]
for x, y in points:
    print(x, y)
🔮 What does contacts["Asha"]["city"] return?

Bengaluru. The first lookup returns a dictionary; the second lookup gets its "city" value.

26 · mini project

Word Frequency Counter

sentence = "the cat sat on the mat the cat ran"
words = sentence.split()

counts = {}

for word in words:
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1

unique_words = set(words)

print(counts)
print("Unique words:", len(unique_words))
🔮 Trace only the first three words: the, cat, sat

After those three words, counts should be {"the": 1, "cat": 1, "sat": 1}. The next occurrence of the or cat increments an existing dictionary value.

✅ Takeaway This one program combines strings, dictionaries, sets, loops, membership testing, and conditional logic.
27 · mental model

The One Decision Guide to Remember

LIST → ordered + changeable TUPLE → ordered + fixed SET → unique + membership DICTIONARY → key → value

When you are unsure, start with the requirement rather than the syntax: Does order matter? Can the data change? Are duplicates allowed? Do I need lookup by name?

Analogy — choosing a container Do not ask “Which structure do I remember?” Ask “What behavior do I need from this collection?”
