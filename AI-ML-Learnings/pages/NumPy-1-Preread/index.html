NumPy 1: Foundations
Storing and Accessing Data

Read this before class. It takes about 10 minutes.

1What's Happening in This Lecture

Here's a sneak peek at everything we cover today, and why each one is worth showing up for.

TopicWhat It Covers
What is NumPy & Importing ItThe module opens with a familiar setup: marks stored in a Python list, and simple requests that a list can't handle without a loop. NumPy (Numerical Python) is the library built for exactly this. Its core object, the ndarray, is a grid of same-type values stored side by side in memory, and it is the engine underneath Pandas, scikit-learn and most of the data stack. You load it with one line: import numpy as np.
Creating ArraysTurn an existing Python list into an array with np.array(), then build the columns an analyst needs from scratch: number sequences with np.arange(), pre-filled starting values with np.zeros() and np.ones(), and evenly spaced boundaries with np.linspace(). The key decision you'll practise is when to specify the step and when to specify the count.
Python Lists vs NumPy ArraysAn array can print almost exactly like a list and still behave completely differently. You'll put the same request through both and see what + and * mean for each, and why an array insists that every value has the same type. This is where vectorization (one operation applied to every value, with no loop) first appears.
Why NumPy Is FasterYou'll time the same job on 10 lakh values twice, once with a Python loop and once with an array, live in the notebook. Then you'll unpack the three reasons behind the gap: how values sit in memory, why a single data type matters, and where the loop actually runs.
Dimensions & Shapendim, shape and size tell you how many dimensions an array has, how long each one is, and how many values it holds. Checking them is an analyst's first sanity step on any new data, much like SELECT COUNT(*) in SQL. You'll also see what a matching count does not prove.
Type Conversion (dtype, astype)Data that looks numeric isn't always numeric. You'll read an array's dtype, see what happens when numbers arrive as text, and fix the type with astype(), the NumPy version of CAST(mark AS INT). Watch for a bug that gives wrong answers without raising any error.
1D Arrays: Indexing & SlicingPull out one value by position, several positions at once (fancy indexing), or a whole range with [start:stop:step], including negative indexes, every-alternate-value steps and reversal. The list slicing rules you already know carry straight over.
2D Arrays: reshape, Indexing, Slicing & TransposeReal data comes in rows and columns. You'll turn one long export into a students × subjects marksheet with reshape(), pull a single cell or a whole block with [row, col], and flip rows into columns with .T. It's the in-memory equivalent of selecting specific rows and columns in SQL.

2Real-World Use Cases

  • What is NumPy & Importing It: A data team's pricing model, recommendation engine and Pandas reports all run on NumPy arrays underneath, which is why import numpy as np is the first line of almost every analytics notebook they open.
  • Creating Arrays: An operations analyst sets up a tracker for 40 stores: store IDs with np.arange(1, 41), a complaints counter that starts at zero, and five equally spaced price bands with np.linspace.
  • Python Lists vs NumPy Arrays: A pricing analyst adds a flat ₹50 delivery charge to every order value in one expression instead of looping over each order.
  • Why NumPy Is Faster: A payments team re-runs a fee calculation on 10 lakh transactions every night; switching from a Python loop to an array operation turns a noticeable wait into a fraction of a second.
  • Dimensions & Shape: Before building a dashboard, an analyst confirms the export has the expected (rows, columns) shape. A missing day of data shows up immediately as one row short.
  • Type Conversion (dtype, astype): A sales analyst discovers that revenue figures were exported as text, so totals came out wrong; converting with astype(float) before aggregating fixes the report.
  • 1D Arrays: Indexing & Slicing: A support lead spot-checks the first 10 tickets in a file and pulls the satisfaction scores of three specific agents by position.
  • 2D Arrays: reshape, Indexing, Slicing & Transpose: A regional manager reshapes a flat monthly export into a 12 × 4 (months × regions) table, slices out Q1 for the South region, and transposes it for a region-wise review.
