Introduction to Machine Learning
⏱ 3 min

Let's think back to our first day of school — teary-eyed, in a room of strangers, watching a teacher draw strange curves on a blackboard. Those curves were numbers. We learnt to recognize them through patterns:

  • A vertical straight line → 1
  • A snake-like shape → 2
  • Grandma's rotated eyeglasses → 8
  • 3 is just an 8 on a diet
🤔 Think about it
We were associating numbers with real-world patterns — that's the seed of machine learning!

The Iron Analogy

Imagine a steam iron — a dragon with a tail blowing hot steam. As a curious child, you might have touched it once. After burning your hand, you never did it again. Why? Because your brain learnt that touching the iron is a bad idea.

Machine Learning is exactly this: finding and learning patterns in data, so future decisions can be smarter.

⚙️
Concept
ML vs Classical Programming
⏱ 5 min

Let's understand this through a concrete task: classifying emails as spam or not spam.

The Classical (SDE) Approach

  1. Look at the data — find patterns like suspicious keywords.
  2. Build rules — write long if-elif-else chains.
  3. Ship it — it works decently, but is brittle.
⚠️ Problems with rule-based systems
If a spammer replaces "lottery" with "lucky draw" or "lotto" — your rules break. Covering every synonym requires thousands of if-else branches. Not feasible.

SDE pipeline: Input text + Hand-written Rules → Decision

The ML Approach

Instead of finding rules yourself, you write algorithms that mine the rules from data.

ML pipeline: Training Data (text + labels) → Learning Algorithm → Trained Model → Prediction

📌 Key Insight
We only use ML when patterns are too complex for humans to write manually, or when we want the system to generalize to similar patterns it hasn't seen.

1

Business Context & Problem Definition

State your goal in non-ML terms first. Understand the industry context — fraud detection in banking looks very different from fraud detection in healthcare.

ApplicationGoal

2

Data Gathering & Understanding

Collect relevant data aligned with the business objective. Understand the features and what they represent.

  • Categorical: car color, engine type (diesel / petrol)
  • Numerical: student weights, house area in sq ft
  • Time Series: stock prices, daily temperatures
  • Text: chatbot conversations, email content
🗑️ Garbage In, Garbage Out
Poor quality data always produces poor models — no matter how sophisticated the algorithm.
🔬
ML Lifecycle
Phases of Machine Learning — Part 2
⏱ 8 min
3

Data Preparation & Cleaning

Data scientists spend the majority of their time here. "Better data beats fancier algorithms."

  • Remove duplicate observations
  • Handle missing values
  • Fix structural errors (e.g., "ML Eng." vs "Machine Learning Engineer")
  • Filter outliers (e.g., someone adding an extra zero to their salary)
4

Exploratory Data Analysis (EDA)

Use statistics and visualizations (pandas, matplotlib) to understand relationships in data:

  • Uni-variate and multi-variate analysis
  • Identify trends and correlations
  • Split into Training set (teaches the model) and Test set (evaluates it)
⚠️ Golden Rule
Never train on test data. The test set must be "unseen" — otherwise your model just memorizes, not generalizes.
5

Model Building

Apply ML algorithms to discover patterns in the prepared data. Try multiple techniques and evaluate performance.

6

Deployment

Make the model available in the real world — as an API (e.g., on AWS) or an interactive web app. A weather model that only lives in a notebook helps no one.

Types of Learning
⏱ 2 min

Toggle between the two primary learning paradigms:

Supervised Learning

The model is trained on labeled data — each input has a corresponding expected output (label).

  • Labeled examples guide the learning process
  • Tasks: Regression, Classification
  • Example: Emails labeled "spam" / "not spam" teach the model to distinguish them

Unsupervised Learning

The model finds patterns in unlabeled data — there are no predefined output labels.

  • No labels provided; the model discovers hidden structure
  • Tasks: Clustering, Dimensionality Reduction
  • Example: Grouping Amazon customers by behavior without any pre-assigned categories
📈
Task Type · Supervised
Regression
⏱ 4 min

The target variable y is a continuous numeric value — it can range from -∞ to +∞.

Example: House Price Prediction

Given features like area, number of rooms, and location — predict the selling price of a house.

  • Input features (X): area, rooms, age, location…
  • Target (y): selling price — a real number
🤔 Think about it
What factors would you personally use to estimate a house's price? Location? Size? Age of the building? All of these become features in a regression model.

Upcoming topics in regression: Linear Regression, Polynomial Regression, Ridge Regression

🏷️
Task Type · Supervised
Classification
⏱ 4 min

The target variable y is a discrete category, not a continuous number.

Example: Cat vs Dog Image Classification

  • Binary Classification: Two categories — Cat (0) or Dog (1)
  • Multiclass Classification: Multiple categories — Cat, Dog, Bird, Fish…

Classification finds a decision boundary (hyperplane) that separates data points of different classes.

🤔 Regression vs Classification?
Regression predicts how much (a number). Classification predicts which category (a label). House price → Regression. Spam or not → Classification.

Upcoming topics: Logistic Regression, Decision Trees, Random Forests, Bagging, Boosting

Task Type · Unsupervised
Clustering
⏱ 4 min

Imagine 100 million Amazon customers described by location, average purchase value, and Prime membership. There are no labels — we want to discover hidden groups.

Why Cluster?

  • Qualitative surveys: survey one representative from each cluster instead of everyone
  • Targeted strategies: offer different discounts to different segments
  • Discover natural groupings you didn't know existed
📌 Definition
Clustering divides data into groups where points within a group are more similar to each other than to points in other groups.

Upcoming topics: K-Means, K-Means++, DBSCAN

Recommendation Systems & Time Series
⏱ 4 min

Recommendation Systems

Think of YouTube's "Up Next" panel. Based on your viewing history — say videos v10, v12, v16 — the system suggests v15 (similar to v12) and v36 (similar to v10).

Core techniques:

  • Collaborative Filtering (Matrix Factorization)
  • Item-Item Similarity
  • Content-Based Similarity

Time Series Forecasting

A time series is data collected at successive, equally-spaced time points — stock prices from 2012–2022, daily taxi fares, hourly temperatures.

Time Series Forecasting uses statistical models to predict future values from past observations.

  • y = stock price
  • t = day index
  • Goal: predict y at future t

Reinforcement Learning
⏱ 6 min

Ever wonder how a game bot beats human players in DOTA or CS:GO? That's Reinforcement Learning.

The Dog Training Analogy

  • ✅ Dog fetches a stick → reward (treat)
  • ❌ Dog chews a slipper → punishment (scolding)

The dog (agent) learns which behaviors to repeat and which to avoid through this feedback loop.

Chess Bot Example

  • Agent: The chess bot
  • Environment: The chess board
  • Interpreter: Evaluates moves and assigns +/- rewards

The loop: Agent acts → Environment changes → Interpreter rewards → Agent updates → repeat indefinitely until the bot becomes a grandmaster.

📌 Real-World Applications
Game bots (Google DeepMind's AlphaGo), robotic path planning, algorithmic trading.
