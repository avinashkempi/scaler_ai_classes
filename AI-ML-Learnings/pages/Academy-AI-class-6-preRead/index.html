n8n, the Same Pipeline Without the Code

Preview how triggers, nodes and connections turn a manual AI script into an automated workflow. You will build support-ticket triage and learn to inspect each run.

About 35–40 minutesRead before classQuick checks included

1. Welcome

Earlier classes used Python to connect input, a model and output. In n8n, you assemble the same shape visually, then add triggers and connections so the process can run without manually launching a script.

What to focus on
Understand the mental model first; you do not need to memorise every detail before class.

2. Triggers, nodes and connections

A trigger starts the workflow, a node performs one step, and a connection passes data onward. The canvas is a map of the process. Connections carry items, commonly JSON objects, and downstream nodes read fields from those items.

3. How data moves

Nodes usually process each incoming item. Five ticket items may cause a node to run five times. Field names matter: a node can only use values present in its incoming item. Inspect input and output instead of assuming the intended fields are there.

4. Node types and credentials

The triage workflow uses a form trigger and an AI step, then may route tickets through a condition and delivery steps such as Telegram or an email draft. Store credentials in n8n's credential system, not in prompts or ordinary workflow data.

5. The support-ticket triage build

The form collects customer email, subject and message. The AI classifies the issue, assesses urgency, identifies a support team and drafts a reply. A condition can route urgent tickets to an alert; draft replies should remain reviewable by a human.

6. Expressions and prompt templates

Expressions insert incoming values into a prompt, such as customer email, subject and message. The expression must use the real incoming field names. A wrong path can evaluate to `undefined`, meaning the model receives incomplete context.

7. Before class: install and test

If possible, have local n8n running and know how to open the editor. Be ready to add your Groq key as an n8n credential and use a Telegram bot for alerts. If local installation fails, use the instructor's Cloud fallback. Import the provided workflow JSON if your live build breaks.

8. Check yourself

Be ready to identify triggers, nodes and connections, explain JSON data flow, diagnose an `undefined` expression and explain why credentials should be stored separately from prompts.
