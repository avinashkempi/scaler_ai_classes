What this post-read covers

Creating and modifying lists, indexing and negative indexing, slicing, common list methods, mutability and aliasing, iterating through lists, and building lists with list comprehensions.

01 · why lists?

What happens when our data gets bigger?

Suppose we want to store the names of five students. We could create five variables.

student1 = "Asha"
student2 = "Rahul"
student3 = "Priya"
student4 = "Arjun"
student5 = "Neha"
🔮 What happens if we have 100 students? 10,000?

Managing separate variable names becomes difficult. A list lets us store multiple values together while keeping their order.

students = ["Asha", "Rahul", "Priya", "Arjun", "Neha"]
✅ TakeawayA list is a collection of values stored together in a specific order.
02 · creating a list

Square brackets create the collection

numbers = [10, 20, 30, 40, 50]

subjects = ["Python", "Math", "Physics"]

answers = [True, False, True]

data = [10, "Python", 3.14, True]

Lists can contain values of different data types. For beginners, however, it is usually clearer to keep related data together.

scores = [85, 90, 78, 92]
💬 Mental modelThink of a list as one labelled container with several positions inside it. The list has one name; each element has a position.

05 · changing elements

Lists are mutable

fruits = ["Apple", "Banana", "Mango"]

fruits[1] = "Orange"

print(fruits)

['Apple', 'Orange', 'Mango']
🔮 Predict the full list before revealing

The element at index 1 changes from "Banana" to "Orange".

📌 Instructor noteA list can be modified after it is created. This is what mutable means in this context.
06 · aliasing

When two names point to the same list

original = ["A", "B", "C"]
alias = original

alias[0] = "X"

print(original)
print(alias)

['X', 'B', 'C']
['X', 'B', 'C']

This can surprise beginners: assigning alias = original does not create an independent copy of the list.

🤖 AI moment 1After running the example, ask an AI assistant: “I have two variable names pointing at what I thought were two separate lists, but changing one changed both. Explain what's actually stored in each variable name.”
🔮 Before asking AI, predict how to fix it
original = ["A", "B", "C"]
alias = original.copy()

alias[0] = "X"

print(original)
print(alias)

Now the two lists are independent. Verify by running the exact code yourself.

✅ TakeawayAI can explain the mechanism, but the learner should independently verify the fix by running the code.
07 · index errors

What if the position does not exist?

fruits = ["Apple", "Banana", "Mango"]
print(fruits[5])
🔮 Predict before running — None, or an error?
IndexError: list index out of range

This list has three elements, so valid positive indexes are 0, 1 and 2.

💬 Beginner checkIf a list has 5 elements, what is its last valid index? 4. General rule: if a list has n elements, indexes run from 0 to n - 1.
08 · slicing

Indexing gives one element. Slicing gives several.

numbers = [10, 20, 30, 40, 50]
print(numbers[1:4])

[20, 30, 40]
🔮 Does index 4 get included?

No. The stop index is excluded. The slice starts at 1 and stops before 4.

✅ Takeawaylist[start:stop] includes start and excludes stop. This is the same exclusive-upper-bound idea you saw with range().
09 · more slicing

Leaving one side empty

numbers = [10, 20, 30, 40, 50]

print(numbers[:3])
print(numbers[2:])
print(numbers[:])

[10, 20, 30]
[30, 40, 50]
[10, 20, 30, 40, 50]
🔮 Predict numbers[:3]

Start is omitted, so Python starts from the beginning: [10, 20, 30].

🔮 Predict numbers[2:]

Stop is omitted, so Python continues to the end: [30, 40, 50].

💬 Mental model[:3] means “from the beginning up to 3.” [2:] means “from 2 to the end.” [:] means “the whole list.”
10 · slicing with a step

[start:stop:step]

numbers = [1, 2, 3, 4, 5, 6]

print(numbers[0:6:2])

[1, 3, 5]
🔮 What does the third number, 2, do?

It means move forward by two positions at a time.

print(numbers[::-1])

[6, 5, 4, 3, 2, 1]
📌 Instructor noteDon't spend too much time on advanced slicing. The essential beginner concept is [start:stop:step], with stop excluded.
11 · list methods

Now we need to work with the data

MethodWhat it does
append(x)Adds x to the end.
insert(i, x)Adds x at index i.
remove(value)Removes the first matching value.
pop(index)Removes and returns an item by index; without an index, removes the last item.
sort()Sorts the existing list in place.
✅ TakeawayThe important distinction is often what the method operates on: remove() uses a value, while pop() uses an index.
12 · append & insert

Adding elements

numbers = [10, 20, 30]

numbers.append(40)
numbers.insert(1, 15)

print(numbers)

[10, 15, 20, 30, 40]
🔮 Where will 15 go?

At index 1, before the current element at index 1.

💬 Memory trickappend() → add at the end. insert() → choose the position.
13 · remove & pop

Removing elements: value vs position

numbers = [10, 20, 30, 40]

numbers.remove(30)
print(numbers)

removed = numbers.pop(1)
print(removed)
print(numbers)

[10, 20, 40]
20
[10, 40]
🔮 Which one uses the value? Which one uses the index?

remove(30) looks for the value 30. pop(1) removes the item at index 1 and gives that removed value back.

14 · sort vs sorted

Two ways to sort — but not the same behavior

numbers = [50, 10, 40, 20, 30]

numbers.sort()
print(numbers)

[10, 20, 30, 40, 50]
🔮 What happens here?
numbers = [50, 10, 40, 20, 30]

sorted_numbers = numbers.sort()

print(sorted_numbers)

None

sort() changes the original list in place and returns None.

🤖 AI moment 2Ask: “I expected sorted_numbers to hold the sorted list, but it's None. Walk me through exactly why, step by step.” Then independently test sorted(numbers).
15 · sorted()

Want a new sorted list?

numbers = [50, 10, 40, 20, 30]

new_list = sorted(numbers)

print(new_list)
print(numbers)

[10, 20, 30, 40, 50]
[50, 10, 40, 20, 30]
sort()sorted()
List methodBuilt-in function
Changes original listLeaves original unchanged
Returns NoneReturns a new sorted list
✅ TakeawayIf you want to change the existing list, use sort(). If you want a sorted result while preserving the original, use sorted().
16 · lists + loops

Visit every element

    print(student)

Asha
Rahul

🔮 Before running, predict all four lines

The loop takes each element from the list one by one and runs the body for that element.

💬 Mental model“Take the next item → put it into student → run the body → repeat until there are no items left.”
17 · index + value

Sometimes you need both

students = ["Asha", "Rahul", "Priya"]

for i in range(len(students)):
    print(i, students[i])

0 Asha
1 Rahul
2 Priya

len(students) gives the number of elements, range() gives the indexes, and students[i] retrieves the value at that index.

18 · conditions + lists

Process each value using a condition

scores = [35, 72, 45, 90, 28]

for score in scores:
    if score >= 40:
        print(score, "Pass")
    else:
        print(score, "Fail")

35 Fail
72 Pass
45 Pass
90 Pass
28 Fail
🔮 Which scores will print “Pass”?

72, 45 and 90. The condition is checked separately for each element.

19 · comprehensions

Build a new list from an existing list

numbers = [1, 2, 3, 4, 5]

squares = []

for number in numbers:
    squares.append(number * number)

print(squares)

[1, 4, 9, 16, 25]
🔮 Can you write the shorter version?
squares = [number * number for number in numbers]

This is a list comprehension. It expresses the same list-building logic more compactly.

✅ TakeawayA list comprehension is not new logic. It is a compact way to express a common loop-based list-building pattern.
20 · comprehension anatomy

Read the expression from left to right

[number * number for number in numbers]
[ ... ]
PartMeaning
number * numberWhat gets placed into the new list.
for number in numbersWhere each input value comes from.
The result is a list.
💬 Read it as“For every number in numbers, put number * number into the new list.”
21 · filtering

Add a condition to the comprehension

numbers = [1, 2, 3, 4, 5, 6]

even_numbers = [
    number for number in numbers
    if number % 2 == 0
]

print(even_numbers)

[2, 4, 6]
🔮 Which numbers survive the condition?

Only values for which number % 2 == 0 is true: 2, 4 and 6.

✅ Pattern[expression for item in iterable if condition]
22 · quick practice

Three tiny comprehensions

🔮 Double every number
numbers = [1, 2, 3, 4]
doubled = [number * 2 for number in numbers]

[2, 4, 6, 8]
🔮 Keep values greater than 5
numbers = [2, 7, 4, 9, 1, 8]
large_numbers = [number for number in numbers if number > 5]

[7, 9, 8]
🔮 Convert names to uppercase
names = ["asha", "rahul", "priya"]
upper_names = [name.upper() for name in names]

['ASHA', 'RAHUL', 'PRIYA']
23 · when to use it

Short and clear vs long and complicated

Beginner ruleShort and clear → list comprehension.

Long or complicated → normal for loop.

You are not expected to force every loop into one line. Readability matters.

24 · practical example

Student Scores — combine today's ideas

scores = [78, 92, 65, 88, 45]

scores.append(95)
scores.sort()

print("Scores:", scores)

for score in scores:
    if score >= 40:
        print(score, "Pass")
    else:
        print(score, "Fail")

passing_scores = [score for score in scores if score >= 40]
print("Passing:", passing_scores)
🔮 Predict the sorted scores before revealing
[45, 65, 78, 88, 92, 95]

All six scores are at least 40, so every score belongs in passing_scores.

✅ What this combinesLists + append() + sort() + for loops + conditions + list comprehensions.
