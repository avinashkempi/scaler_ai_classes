01 The four data types

Every cell in Superstore belongs to one of four types. GSheets guesses the type from what you type — misclassify one, and a downstream SUM or Pivot Table breaks silently, with no error message telling you why.

The Workflow

02 Data cleaning — 6 steps

Click each "Apply" button to watch the row transform. Same trick works in real Sheets: Data → Data cleanup, or a formula in a helper column.

1

Remove duplicates

Identical rows silently double your totals.

In real Sheets: select all data → Data → Data cleanup → Remove duplicates → keep "Data has header row" checked and every column selected, so only rows where every cell matches get dropped.

Rows are editable — click a cell and change it, then check for duplicates. Try making them differ by just one character.

2

Trim whitespace

A trailing space is invisible to you, but real data to GSheets.

In real Sheets: highlight the text columns (City, Postal_Region, Product ID) → Data → Data cleanup → Trim whitespace. A pop-up tells you exactly how many cells were cleaned.

3

Handle missing values

A blank cell is a decision, not a bug — pick a strategy.

In real Sheets: Data → Create a filter → click the filter icon on the column → uncheck everything except "(Blanks)" to isolate the broken rows → highlight them and use Ctrl+Enter (Windows) / Cmd+Enter (Mac) to bulk-fill every selected blank at once.

Removal deletes the row entirely (use when critical info can't be recovered). Imputation estimates from other clues (Postal Code + City/State). Categorization labels it "Unknown" so Pivot Tables show a clean slice instead of a messy blank.
4

Standardize text casing

=PROPER() collapses fake categories into one real one.

In real Sheets: insert a helper column, write =PROPER(D2), drag it down, copy the results, then right-click the original column → Paste Special → Values only before deleting the helper column. Never overwrite raw data with a live formula.

5

Date transformation

A date stored as text can't be sorted, filtered, or subtracted.

In real Sheets, this is a two-stage fix. Stage 1 — fix the delimiter: select the column, press Ctrl+H (Windows) / Cmd+Shift+H (Mac), Find "." Replace with "/", Replace all. Stage 2 — apply a consistent format: select the column → Format → Number → Date.

6

Text splitting

One column hiding two dimensions — the slash is your delimiter.

In real Sheets: first insert an empty column to the right so the split doesn't overwrite adjacent data, then highlight the column → Data → Split text to columns → change "Detect automatically" to Custom and type your delimiter.

Formula Toolkit

03 Text functions playground

Menu-driven cleaning is one-off; formulas scale to every new row. Type any value into the cell below — try a Product ID like FUR-CH-10000454 or a messy price like $261.96 — and watch every function recalculate live.

FunctionWhat it doesWhy it matters
LENCounts characters in a cellThe #1 detective tool — if every Customer ID should be 8 characters and LEN returns 7, that row is broken
LEFT / RIGHT / MIDSlice N characters from the start, end, or middleSplits a Product ID like FUR-CH-10000454 into Category, Sub-Category, and Item Code without ever touching the raw column
FIND / SEARCHReturns the position of a character inside a cellLocates a delimiter dynamically, so LEFT(text, FIND("/",text)-1) works whether the code is 5 digits or 7
SUBSTITUTESwaps one piece of text for another, non-destructivelyStrips symbols like $ so a price hiding as text can be forced back into a real number
PROPER / UPPER / LOWERStandardizes casingCollapses "los angeles", "LOS ANGELES", and "Los Angeles" into one real category
Live cell: F2. All formulas below reference this value.
=LEN(F2)
=LEFT(F2,3)
=MID(F2,5,2)
=RIGHT(F2,4)
=FIND("/",F2)
=SUBSTITUTE(F2,"-","_")
=PROPER(F2)
=SUBSTITUTE(F2,"$","")*1
Interview hook: given only a Product ID column, LEFT(Product_ID,3) inside a COUNTIF gets you a category count without ever building a Category column.
Sibling functions: UPPER() and LOWER() do the same job as PROPER() for ALL CAPS and all lowercase output. They're most useful for standardizing join keys before a VLOOKUP — two ID columns that look identical to you can still fail to match if one is uppercase and the other isn't.
Putting it together: before any deep analysis, build a few helper columns once — =LEFT(F2,3) for Category Code, =MID(F2,5,2) for Sub-Category Code, =LEN(C2) to flag any Customer ID with the wrong length. Three formulas, dragged down once, and the dataset is segmentation-ready. Menu-driven cleaning is one-off — formula-driven cleaning scales every Monday morning.

04 Date & time lab

GSheets stores every date as a serial number — days since December 30, 1899. That single fact is why date subtraction, sorting, and filtering all just work.

Serial number decoder

Internally stored as 41799
=YEAR() → 2014 =MONTH() → 6 =DAY() → 9 =WEEKDAY(,2) → 1

"D" "M" "Y"

DATEDIF unitReturns

Interview reality: a data analyst interview will almost always include a date question — "how many days between order placed and delivered," "what was the average delivery time last quarter," "which day of the week sees the most orders." These aren't optional skills; they're entry-level expectations. Build the helper columns once — =YEAR(B2) for year-over-year analysis, =MONTH(B2) for seasonality, =WEEKDAY(B2,2) for weekday-vs-weekend effects, =TODAY()-B2 for order-aging buckets — and every future date question becomes a one-liner.

05 Sort sheet vs. sort range

Same button family, opposite outcomes. One keeps every row intact; the other quietly breaks the link between columns.

Multi-level sorting: real datasets rarely need just one sort key. To find the top 5 sales in each region, use Data → Sort range → Advanced range sorting options, check "Data has header row," sort by Region (A→Z) first, then click "+ Add another sort column" and sort by Sales (Z→A). The first 5 rows of each region block are your answer — a technique that combines cleanly with the fill handle's double-click shortcut to auto-fill down to the last row of data.

Field Notes

06 3 beginner mistakes

1 Sorting only one column

Highlighting just the Sales column and sorting it leaves every other column in its original order. Fix: always use Data → Sort sheet, not Sort range.

2 Forgetting helper columns

Cleaning directly inside the original column overwrites raw data with formula results — nothing to go back to if the formula is wrong. Fix: build a helper column, verify it, then Paste Special → Values only.

3 Formatting numbers instead of converting them

A cell that looks like $261.96 may still be text — left-aligned is the tell. SUM and Pivot Tables will silently return 0. Fix: =SUBSTITUTE(A2,"$","")*1 forces it back into a real number.

4 Cleaning before understanding the data types

Jumping straight into TRIM and PROPER without first checking whether a column is text, a number, a date, or a boolean means the same misclassification keeps resurfacing — a "clean" date column can still silently be text underneath. Fix: always confirm the data type first (numbers are right-aligned, text is left-aligned) — misclassifying a type breaks every downstream calculation, and no amount of formatting fixes that.

Check Yourself

08 Quick quiz

1. Why is removing duplicates one of the first steps in data cleaning?
Duplicate rows can silently double-count sales, customers, or transactions — leading to incorrect totals and misleading reports.
2. Which function best standardizes "los angeles" into "Los Angeles"?
PROPER() capitalizes the first letter of each word and lowercases the rest, standardizing categorical text fields.
3. What does =DATEDIF(Order_Date, Ship_Date, "D") return?
DATEDIF with unit "D" returns the total number of days between the two dates.
4. What does =YEAR(Order_Date) return for 09-Jun-2014?
YEAR() extracts only the year portion of a date value.
