Why this order?The before picture comes first, so you can say later that nothing else moved. The test is written and run before the fix, so you know it can fail, and that it fails for the right reason. A second red test after the first fix is a gift: it shows the same mistake in a second place. Only then do you run everything, compare fingerprints, and ask the machine to check it again on a clean computer through the pull request.

Which kind of check?

  

  
Match the check to its questionA unit check asks about one function. A contract asks about a shape. A regression asks whether an old failure came back. An end-to-end check asks about a whole run. A capability case asks about something we may not pass yet.

Cheat sheet

  
You do not need to memorise any of it. You need to recognise it and know what question it answers.

  
Five kinds of check

  

  

    
KindMarkerThe question it asksExample

    
UnitunitDoes this one function do its job?parse_units("14") is 14

    
ContractcontractDoes this record, reply or log line have the promised shape?A reply with an unknown key is refused

    
RegressionregressionHas a failure we already saw come back?parse_units("١٢") is refused

    
End to ende2eDoes a whole run behave?The same input gives the same files

    
CapabilitycapabilityCan it do this harder thing yet?G-09 should abstain, and does not yet

  

  

  
What a red line usually means

  

  

    
You seeIt usually means

    
Failed: DID NOT RAISEThe code accepted something it should refuse. For a new regression test, this is the right red

    
assert 2 == 1 on a call countThe code made a call the test did not expect

    
[XPASS(strict)]An expected failure has started to pass. Remove the marker and raise the floor

    
'regresion' not found in markersA misspelled marker, caught by --strict-markers

    
Green here, red in CIThe clean machine lacks something your laptop has. Check requirements.txt

    
RuntimeError: network access is blocked ...A routine test tried to reach the network. Use a fake model
