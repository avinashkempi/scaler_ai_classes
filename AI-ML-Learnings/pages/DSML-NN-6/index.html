Backpropagation through a two-layer network: from the chain rule to a trained classifier.

The data and the network

The running example is a spiral dataset: 300 points, two features per point, and three classes (A, B, C). X holds the features and y holds the class labels.

python
import pandas as pd
import numpy as np

df = pd.read_csv("spiral.csv")

# Separating feature and label columns
X = df.iloc[:, :-1].to_numpy()
y = df.iloc[:, -1].to_numpy()

Earlier, a single softmax layer sat directly on top of the inputs. Now a hidden ReLU layer goes in between: its output becomes the input to the output layer. Select a layer to see what it holds.

Anatomy of the 2 → 4 → 3 networkSelect a layer

Sizes and parameters

Three sizes define the network: d = 2 inputs, h = 4 neurons in the hidden layer, and n = 3 neurons in the output layer (one per class). Each layer has a weight matrix and a bias row.

ParameterShapeRole
W1(d, h) = (2, 4)Inputs → hidden layer
b1(1, h) = (1, 4)Hidden-layer bias
W2(h, n) = (4, 3)Hidden layer → output layer
b2(1, n) = (1, 3)Output-layer bias
2

Forward propagation

The forward pass turns X into class probabilities. Each operation is a node in the network's computational graph, and the same graph is what the backward pass will walk in reverse. Step through it below.

Computational graph: forward passStep through the computation

Weights start as small random numbers and biases start at zero.

# initialize parameters randomly
d = 2 # dimensionality / number of inputs
n = 3 # Number of classes (A/B/C) / Number of neurons in output layer
h = 4 # neurons in hidden layer

W1 = 0.01 * np.random.randn(d,h)
b1 = np.zeros((1,h))
W2 = 0.01 * np.random.randn(h,n)
b2 = np.zeros((1,n))

Multiply every row of X with every column of W1, then add the bias by broadcasting: X · W + b.

Z1 = np.dot(X, W1) + b1 # (300,2) x (2,4) + (1,4) => (300,4)
A1 = np.maximum(0, Z1)  # ReLU: if Z1 < 0 then A1 = 0, else A1 = Z1

To reach a shape of (300, 3), multiply A1 by W2 and add b2. Softmax then turns each row of scores into probabilities.

Z2 = np.dot(A1, W2) + b2  # (300, 4) x (4, 3) + (1, 3) => (300, 3)
# Applying softmax function to get A2
Z2_exp = np.exp(Z2)
A2 = Z2_exp/np.sum(Z2_exp, axis=1, keepdims=True)
probs = A2
One extra line

Compared with the single softmax layer, the only change is one extra line of code: compute the hidden-layer representation first, then treat it as the input to the output layer.

Notation: derivations write Z2 = (W2)T·A1 + b2 (one example at a time), while the code works on all rows at once as A1 · W2 + b2. The two describe the same computation.

3

Loss: what changes, what doesn't

Adding a hidden layer changes how the probabilities are produced, not how they are scored. The loss is the same categorical cross-entropy as before: the average negative log of the probability given to each example's correct class.

L = −1m Σi log pi, y(i)
# Number of training examples
m = y.shape[0] # 300 datapoints
Loss

Unchanged. It only reads the final probabilities A2.

Gradient rule

Unchanged. Each gradient still comes from the chain rule.

Backpropagation

The gradients now have to be passed back through one additional layer.

4

Backpropagation

Backpropagation applies the chain rule from the loss backwards, one layer at a time. Here is the whole backward pass on the same graph. The sections after it derive each step.

Computational graph: backward passStep through the gradients

Step 1: dZ² at the output

The gradient of the loss with respect to the output scores splits into two factors:

dZ2 = ∂L∂Z2 = ∂L∂A2 · ∂A2∂Z2

Here A2 is the vector of output probabilities p, so this is ∂L/∂p · ∂p/∂Z2. That is exactly the derivative already worked out for the softmax classifier, dz = ∂J/∂p · ∂p/∂z, and it came out as

dZ2 = pi − 1(i = y)

In words: the predicted probability of every class, minus 1 for the true class. Because dZ2 has the same shape as the probabilities, it is (m, 3) = (300, 3).

dZ2 = probs
dZ2[range(m),y] -= 1
dZ² for one exampleIllustrative scores; change them and the true class

Scores Z² for one example

True class y

Probabilities p (softmax of the scores)

dZ² = p − 1(i = y)

Step 2: dW² and db²

These follow the same pattern as dW and db in the softmax classifier. Extending the chain by one more factor:

dW2 = ∂L∂W2 = ∂L∂A2 · ∂A2∂Z2 · ∂Z2∂W2 = dZ2 · ∂Z2∂W2

Since Z2 is linear in W2, the local derivative ∂Z2/∂W2 is A1, so dW2 = dZ2 · A1. The order and transposes are settled by shapes.

Getting the matrix multiplication right

  • dZ2 has shape (300, 3) and A1 has shape (300, 4).
  • dW2 is used to update W2, so it must have W2's shape: (4, 3).
  • Transposing A1 gives (4, 300) × (300, 3) = (4, 3).
dW2 = (A1)T · dZ2
Shape checkerChoose a gradient, then try it without the transpose

Why divide by m?

In gradient descent every data point contributes to the update, so the update uses their average. That means dividing by the number of examples, m. There are two equivalent places to do it:

In the gradients

Divide while computing dW2, db2, dW1, db1. This is what the code here does.

In the update

Divide when applying the step: w1 = w1 − η · dw1 · 1m.

# shape A1 => (300,4)  shape dZ2 (equal to probability) => (300,3)
dW2 = np.dot(A1.T, dZ2)/m # shape => (4, 300) x (300, 3) => (4,3)

The bias gradient

Because ∂Z2/∂b2 = 1, the bias gradient equals dZ2:

db2 = ∂L∂A2 · ∂A2∂Z2 · 1 = dZ2

db2 updates b2, so its shape must be (1, 3), but dZ2 is (300, 3). Since this is gradient descent (not SGD), the per-example derivatives are summed across the rows and then averaged.

db2 = np.sum(dZ2, axis=0, keepdims=True)/m # shape (1 ,3)

Step 3: dA¹, the gradient that crosses the layer

We are not done yet: A2 also depends on Z1, and through it on W1 and b1. To get dW1 and db1 we first need dZ1, and before that dA1.

dA1 = ∂L∂A1 = ∂L∂A2 · ∂A2∂Z2 · ∂Z2∂A1 = dZ2 · W2

The first two factors are already dZ2, and ∂Z2/∂A1 = W2. The result has the same shape as A1: (300, 4).

For the multiplication, dZ2 is (300, 3) and W2 is (4, 3), while the target is (300, 4). So multiply by the transpose of W2: (300, 3) × (3, 4) = (300, 4).

dA1 = dZ2 · (W2)T
dA1 = np.dot(dZ2, W2.T) # (300,3) x (3 , 4) => (300, 4)

Step 4: dZ¹ through the ReLU

Next the gradient passes back through the ReLU layer. The chain gains one factor, ∂A1/∂Z1:

dZ1 = ∂L∂Z1 = ∂L∂A2 · ∂A2∂Z2 · ∂Z2∂A1 · ∂A1∂Z1 = dA1 · ∂A1∂Z1

The ReLU passes positive values through unchanged and outputs 0 for the rest, so its derivative is 1 where Z1 > 0 and 0 elsewhere. In code, that means zeroing dA1 wherever Z1 <= 0. The shape of dZ1 matches Z1: (300, 4).

dA1[Z1 <= 0] = 0
dZ1 = dA1 # same shape as dA1 (300, 4)
ReLU as a gradient gateIllustrative values; move the sliders

Each hidden unit has an incoming gradient dA¹ (fixed here). Change Z¹ and see whether the gradient gets through.

Why overwrite dA¹ instead of copying it?

dA1 and dZ1 exist only to produce dW1 and db1. Once dZ1 is computed, dA1 is never used again, so editing it in place loses nothing.

It also means the forward pass has to save its intermediate values, since the backward pass needs them.

For a ReLU, A1 <= 0 and Z1 <= 0 select the same entries, so the NN class later on, which checks A1, behaves identically.

Step 5: dW¹ and db¹, then the update

The last two gradients repeat the pattern from the output layer. For the weights, extend the chain by ∂Z1/∂W1 = X; for the bias, by ∂Z1/∂b1 = 1:

dW1 = ∂L∂W1 = dZ1 · ∂Z1∂W1 = dZ1 · X
db1 = ∂L∂b1 = dZ1 · ∂Z1∂b1 = dZ1 · 1

With the same shape logic as before (see the shape checker above), dW1 is (2, 4) and db1 is (1, 4).

dW1 = np.dot(X.T, dZ1)/m # (2, 300) x (300 ,4) => (2, 4)
db1 = np.sum(dZ1, axis=0, keepdims=True)/m

With all four gradients in hand, each parameter takes a gradient-descent step, and the cycle repeats until it converges (the error goes down).

lr = 1e-0

# perform a parameter update
W1 += -lr * dW1
b1 += -lr * db1
W2 += -lr * dW2
b2 += -lr * db2

Putting it together: reuse and caching

Look at how the derivatives depend on each other. dZ2 feeds dW2, db2 and dA1; dA1 feeds dZ1; and dZ1 feeds dW1 and db1. So each deeper derivative is computed once and stored, then reused by the shallower ones. This is memoization, the same idea used in dynamic programming.

Chain rule with memoizationPick a parameter and see which prefix is reused

The forward pass therefore caches what the backward pass will need. For example, dA1 uses W2. Here is every gradient with its formula, shape, and the stored values it needs:

Full training loop (h = 100, 10,000 iterations) 
# initialize parameters randomly
d = 2
h = 100 # size of hidden layer
n = 3
W1 = 0.01 * np.random.randn(d,h)
b1 = np.zeros((1,h))
W2 = 0.01 * np.random.randn(h,n)
b2 = np.zeros((1,n))

# some hyperparameters
lr = 1e-0
reg = 1e-3 # regularization strength
num_examples = X.shape[0]

for i in range(10000):

    # forward prop
    Z1 = np.dot(X, W1) + b1
    A1 = np.maximum(0, Z1)
    Z2 = np.dot(A1, W2) + b2
    Z2 = np.exp(Z2)
    A2 = Z2 / np.sum(Z2, axis=1, keepdims=True)
    probs = A2

    # calc. loss
    correct_logprobs = -np.log(probs[range(num_examples),y])
    data_loss = np.sum(correct_logprobs)/num_examples
    loss = data_loss
    if i % 1000 == 0:
        print("iteration %d: loss %f" % (i, loss))

    # backprop
    # compute the gradient on scores
    dZ2 = probs
    dZ2[range(num_examples),y] -= 1
    dZ2 /= num_examples

    # first backprop into parameters W2 and b2
    dW2 = np.dot(A1.T, dZ2)
    db2 = np.sum(dZ2, axis=0, keepdims=True)
    # next backprop into hidden layer, A1
    dA1 = np.dot(dZ2, W2.T)
    # backprop the ReLU non-linearity
    dA1[Z1 <= 0] = 0
    # finally into W,b
    dZ1 = dA1
    dW1 = np.dot(X.T, dZ1)
    db1 = np.sum(dZ1, axis=0, keepdims=True)

    # perform a parameter update
    W1 += -lr * dW1
    b1 += -lr * db1
    W2 += -lr * dW2
    b2 += -lr * db2

Here dZ2 /= num_examples takes care of the averaging, so the later gradients need no division. This loop defines reg but does not apply it; the NN class in section 6 does.

Wrapping it all in a class

Everything above packages neatly into one reusable NN class: parameters are set up in __init__, and forward propagation, loss, backpropagation, training and prediction each get a method. Pick a method to read it.

Stores the sizes and creates the four parameter arrays.

class NN:

    def __init__(self, n_features, n_hidden, n_classes):
        self.d = n_features
        self.h = n_hidden
        self.n = n_classes
        self.W1 = 0.01 * np.random.randn(self.d, self.h)
        self.b1 = np.zeros((1,self.h))
        self.W2 = 0.01 * np.random.randn(self.h,self.n)
        self.b2 = np.zeros((1,self.n))

The forward pass; returns the hidden activations and the output probabilities.

    def fwd_prop(self, X):
        Z1 = np.dot(X, self.W1) + self.b1
        A1 = np.maximum(0, Z1)
        Z2 = np.dot(A1, self.W2) + self.b2
        Z2 = np.exp(Z2)
        A2 = Z2 / np.sum(Z2, axis=1, keepdims=True)
        return A1, A2

Categorical cross-entropy: average negative log-probability of the correct class.

    def cce_loss(self, y, probs):
        num_examples = y.shape[0]
        correct_logprobs = -np.log(probs[range(num_examples),y])
        loss = np.sum(correct_logprobs)/num_examples
        return loss

The five gradients from section 4, in order: dZ², then dW² and db², then dA¹, dZ¹, and finally dW¹ and db¹.

    def back_prop(self, X, A1, A2, y):
        # compute the gradient on scores
        num_examples = y.shape[0]
        dZ2 = A2
        dZ2[range(num_examples),y] -= 1
        dZ2 /= num_examples
        # first backprop into parameters W2 and b2
        dW2 = np.dot(A1.T, dZ2)
        db2 = np.sum(dZ2, axis=0, keepdims=True)
        # next backprop into hidden layer, A1
        dA1 = np.dot(dZ2, self.W2.T)
        # backprop the ReLU non-linearity
        dA1[A1 <= 0] = 0
        # finally into W,b
        dZ1 = dA1
        dW1 = np.dot(X.T, dZ1)
        db1 = np.sum(dZ1, axis=0, keepdims=True)
        return dW1, db1, dW2, db2

The training loop. Unlike the earlier loop, this version adds L2 regularization to the loss and to the weight gradients.

    def fit(self, X, lr, reg, max_iters):
        num_examples = X.shape[0]
        for i in range(max_iters):
            #foward prop
            A1, A2 = self.fwd_prop(X)
            # calculate loss
            data_loss = self.cce_loss(y, A2)
            reg_loss = 0.5*reg*np.sum(self.W1*self.W1) + 0.5*reg*np.sum(self.W2*self.W2)
            loss = data_loss + reg_loss

            if i % 1000 == 0:
                print("iteration %d: loss %f" % (i, loss))

            dW1, db1, dW2, db2  = self.back_prop(X, A1, A2, y)

            # add regularization gradient contribution
            dW2 += reg * self.W2
            dW1 += reg * self.W1

            # perform a parameter update
            self.W1 += -lr * dW1
            self.b1 += -lr * db1
            self.W2 += -lr * dW2
            self.b2 += -lr * db2

fit reads the labels y from the surrounding notebook scope; they are not a parameter of the method.

Runs the forward pass and returns the index of the highest score as the predicted class.

    def predict(self, X):
        A1 = np.maximum(0, np.dot(X, self.W1) + self.b1) # ReLU(Z1) = ReLU(W1T. X + b1)
        Z2 = np.dot(A1, self.W2) + self.b2 # Z2 = W2T.A1 + b2 => 3 probab
        y_hat = np.argmax(Z2, axis=1) # taking index of max probab
        return y_hat

Softmax never changes which score is largest, so taking the argmax of Z2 picks the same class as the argmax of the probabilities.

Create the model, fit it, then draw its decision regions over a 2D grid with the data on top.

nn_model = NN(n_features=2, n_hidden=100, n_classes=3)
nn_model.fit(X, lr=1, reg=1e-3, max_iters=10000)
print('training accuracy: %.2f' % (np.mean(nn_model.predict(X) == y)))
from matplotlib import pyplot as plt

# create a 2D grid
step = 0.02
x_min, x_max = X[:, 0].min() - 1, X[:, 0].max() + 1
y_min, y_max = X[:, 1].min() - 1, X[:, 1].max() + 1
xx, yy = np.meshgrid(np.arange(x_min, x_max, step), np.arange(y_min, y_max, step))

# predict for all the points in the grid
y_hat = nn_model.predict(np.c_[xx.ravel(), yy.ravel()])
y_hat = y_hat.reshape(xx.shape)

# plot
fig = plt.figure()
plt.contourf(xx, yy, y_hat, cmap=plt.cm.Spectral, alpha=0.8)
plt.scatter(X[:, 0], X[:, 1], c=y, s=40, cmap=plt.cm.Spectral)
plt.xlim(xx.min(), xx.max())
plt.ylim(yy.min(), yy.max())
plt.show()

The same idea in scikit-learn

Each unit of a neural network is also called a perceptron, so a neural network is also called a multi-layer perceptron (MLP). scikit-learn provides one as MLPClassifier.

from sklearn.neural_network import MLPClassifier
mlp = MLPClassifier(solver='lbfgs',
                    alpha=1e-5,
                    hidden_layer_sizes=(100),
                    random_state=100,
                    activation='relu',
                    max_iter=200)
mlp.fit(X, y)
print(mlp.score(X, y))

Neural networks for regression

So far the network has solved classification. It can do regression too, and what decides is the last neuron in the chain:

  • If the last neuron is linear, the network does regression. Example: y = x.
  • If the last neuron is probabilistic (sigmoid or softmax), the network does classification. Example: y = sig(x).
Last neuron: linear or probabilisticToggle the output type

Input x to the last neuron: 2.0

Hidden layers must stay non-linear

The intermediate layers should never be linear. If they were, the network could not build the high-order, complex features that make it powerful. The activations in hidden layers are always non-linear; only the output neuron changes between regression and classification.

9

Wrap-up

From manual gradients to autograd

Everything derived by hand here (dZ2, dW2, dA1, dZ1, …) is exactly what deep learning frameworks such as TensorFlow and PyTorch compute automatically, using autograd (automatic differentiation). Those frameworks are next.

  • Forward propagation for a 2-layer network: Z1 → A1 → Z2 → A2, built on the computational graph.
  • The loss stays the same; backpropagation just extends one more layer back.
  • Gradients derived step by step: dZ2 → dW2, db2 → dA1 → dZ1 → dW1, db1, each reusing the one before it.
  • Parameters updated with gradient descent, repeated until the error goes down.
  • The whole network packaged as a reusable Python class.
  • The same model trained with scikit-learn's MLPClassifier.
  • Regression uses a linear last neuron; hidden layers always stay non-linear.
