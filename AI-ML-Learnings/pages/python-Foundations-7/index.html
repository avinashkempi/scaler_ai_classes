01 · strings, the idea

What exactly is a string?

Whenever we write text inside quotes, we are working with a string. A string is a sequence of characters, and each character has a position. That means the indexing idea students already know from Lists carries directly over to strings.

name = "Asha"
subject = 'Python'
message = "Welcome to the class!"

word = "Python"
print(word)

02 · creating strings

Single quotes or double quotes?

Both single quotes and double quotes create strings. Spaces and punctuation are also part of the string. For beginner code, consistency matters more than choosing one particular quote style.

name = 'Asha'
subject = "Python"
message = "Welcome to Python!"
message2 = "It's a great day!"

All four variables contain strings.
🔮 Predict before revealing — what should happen here?

💬 Use one quote style consistently. Double quotes are convenient when the text contains an apostrophe.

03 · indexing

One character at a time

A string is a sequence, so every character has an index. Python starts counting at 0 — exactly the same rule students used with lists.

word = "Python"

print(word[0])
print(word[3])

💬 Indexing gives you one character. The first character is at index 0.

04 · negative indexing

Counting from the end

Negative indexes count backward from the end. The last character is -1, the one before it is -2, and so on.

word = "Python"

print(word[-1])
print(word[-2])

n
o
🔮 Predict before revealing — what should happen here?

💬 Positive indexes count from the beginning; negative indexes count from the end.

05 · slicing

From one character to a portion

Indexing gives one character. Slicing gives a portion of the string using start:stop. The start is included, but the stop is excluded.

word = "Python"

print(word[0:3])

🔮 Predict before revealing — what should happen here?

💬 Index 3, the h, is not included. This is the same exclusive-stop rule students already saw with list slicing and range().

06 · more slicing

The shortcuts

Leaving one side of the colon blank tells Python to use the beginning or the end automatically. Leaving both blank copies the whole string.

word = "Python"

print(word[:3])
print(word[2:])
print(word[:])

Pyt
thon
Python
🔮 Predict before revealing — what should happen here?

💬 Remember: [:3] means “from the beginning up to, but not including, 3”; [2:] means “from 2 to the end.”

07 · step & reverse

Skipping characters — and going backward

A third slicing value is the step. A negative step moves backward. This reuses the slicing idea from Lists.

word = "Python"

print(word[::2])
print(word[::-1])

nohtyP
🔮 Predict before revealing — what should happen here?

💬 Step 2 takes every second character. Step -1 walks backward through the string.

08 · length

How many characters?

len() tells us how many characters are in a string. Spaces count too. Because indexing starts at 0, a string with 10 characters has 9 as its last valid index.

name = "Asha"
print(len(name))

message = "Hello World"
print(len(message))

10 · lower & upper

Normalize the case

lower() converts letters to lowercase and upper() converts them to uppercase. This is especially useful when user input can arrive in different cases.

text = "Hello Python"

print(text.lower())
print(text.upper())

hello python
HELLO PYTHON
🔮 Predict before revealing — what should happen here?

💬 Case normalization lets you compare input such as YES, Yes, and yes consistently.

11 · title & strip

Format names and clean input

title() capitalizes the first letter of each word. strip() removes whitespace from the beginning and end — but not spaces between words.

name = " asha sarkar "

print(name.title())
print(name.strip())

 Asha Sarkar 
asha sarkar
🔮 Predict before revealing — what should happen here?

💬 Be careful: strip() removes outer whitespace only. It does not remove the space between “Asha” and “Sarkar”.

12 · replace

Create changed text

replace() replaces matching text and returns the resulting string. It replaces every matching occurrence in the string.

message = "I like Java"
message = message.replace("Java", "Python")
print(message)

text = "banana"
print(text.replace("a", "o"))

I like Python
bonono
🔮 Predict before revealing — what should happen here?

💬 Notice the result is assigned back to message. This connects directly to string immutability.

13 · find

Where does this text start?

find() searches for a substring and returns its starting index. If the substring is not found, it returns -1 rather than raising an error.

text = "I love Python"

print(text.find("Python"))
print(text.find("Java"))

🔮 Predict before revealing — what should happen here?

💬 Think of find() as “tell me where this starts, or tell me -1 if it isn't there.”

14 · starts & ends

Boolean questions about text

startswith() and endswith() answer simple yes/no questions and therefore return Boolean values.

filename = "report.pdf"

print(filename.startswith("report"))
print(filename.endswith(".pdf"))

💬 These methods fit naturally into conditions, for example checking whether a filename ends with .txt.

15 · split

String → list

split() breaks a string into a list of pieces. This is an important bridge between the Strings class and the Lists class.

sentence = "Python is easy"
words = sentence.split()

print(words)

['Python', 'is', 'easy']
🔮 Predict before revealing — what should happen here?

💬 One string becomes multiple list elements. By default, whitespace separates the pieces.

16 · split with a separator

Choose what separates the pieces

You can provide a separator explicitly. This is common when processing comma-separated or similarly structured text.

data = "apple,banana,mango"
fruits = data.split(",")

print(fruits)

['apple', 'banana', 'mango']
🔮 Predict before revealing — what should happen here?

💬 The comma is the separator, so it does not become part of any resulting item.

17 · join

List → string

join() performs the opposite kind of transformation: it combines strings from an iterable into one string. The separator is written before .join().

words = ["Python", "is", "fun"]

sentence = " ".join(words)
print(sentence)

fruits = ["Apple", "Banana", "Mango"]
result = ", ".join(fruits)
print(result)

Python is fun
Apple, Banana, Mango
🔮 Predict before revealing — what should happen here?

💬 Read " ".join(words) as “join these words using a space.”

18 · immutability

The big idea: strings cannot be changed in place

Strings are immutable. Once a string exists, you cannot replace one character inside that existing string. String methods return new strings instead of modifying the original string in place.

word = "Python"

word[0] = "J"

TypeError: 'str' object does not support item assignment
🔮 Predict before revealing — what should happen here?

💬 Lists are mutable; strings are immutable. This difference becomes important when students move between the two data structures.

19 · methods return new strings

Why didn't upper() change the variable?

Calling a string method does not automatically replace the variable's value. If you want the new string, assign the returned result back to the variable.

text = "hello"

text.upper()
print(text)

text = text.upper()
print(text)

hello
HELLO
🔮 Predict before revealing — what should happen here?

💬 Think: the original string stays unchanged; the method gives you another string.

20 · f-strings

Dynamic text without messy concatenation

f-strings let you place variables directly inside a string using {}. They are especially useful when a sentence contains several variables or expressions.

name = "Asha"
age = 20

print(f"My name is {name} and I am {age} years old.")

My name is Asha and I am 20 years old.
🔮 Predict before revealing — what should happen here?

💬 An f-string evaluates the expressions inside { } and inserts their values into the text.

21 · f-string expressions

The braces can contain expressions

Anything inside the braces is evaluated. This means an f-string can include calculations, not just simple variable names.

price = 100
quantity = 3

print(f"Total: {price * quantity}")
print(f"Price: {price:.2f}")

Total: 300
Price: 100.00
🔮 Predict before revealing — what should happen here?

💬 f-strings combine text formatting with normal Python expressions.

22 · escape characters

When a character needs special meaning

A backslash introduces an escape sequence. Common examples are \n for a new line, \t for a tab, and escaped quotation marks.

print("Hello\nWorld")
print("Name:\tAsha")
print("He said \"Hello\"")

💬 Escape characters let you represent formatting or quote characters inside strings.

24 · strings + conditions

Combine concepts

String methods, loops, and conditions can work together. For example, we can inspect every character and count vowels.

word = "education"
count = 0

for character in word:
    if character in "aeiou":
        count += 1

print("Vowels:", count)

Vowels: 5
🔮 Predict before revealing — what should happen here?

💬 This is the larger mental model: strings provide the data, loops process it, and conditions decide what to do.

25 · input pipeline

Clean user input in one line

Methods can be chained when each method returns another string. This is a practical pattern for cleaning user input before using it.

name = input("Enter your name: ").strip().title()

print(f"Hello, {name}!")

Input → strip() → title() → f-string
🔮 Predict before revealing — what should happen here?

💬 Read the chain from left to right: get text → clean outer spaces → format capitalization → insert into the message.
