Multivariable functions

So far every function took a single input, x. Many real functions depend on several inputs at once — for example f(x, y) = x² + y² takes two numbers and still returns just one output.

A multivariable function can be thought of as accepting a vector of inputs and returning a single scalar value — exactly the shape of a machine-learning loss function, which depends on many weights at once.

Partial derivatives

To differentiate a function of several variables, hold every variable except one constant and differentiate with respect to that one variable alone. Because only part of the function is varying, this is called a partial derivative, written with the symbol ∂ ("del", "doh", or "dee").

Worked example: f(x, y) = x² + y²

∂f/∂x = 2x   (treating y² as a constant, whose derivative is 0)
∂f/∂y = 2y   (treating x² as a constant, whose derivative is 0)

∂f/∂x tells you the rate of change of the function purely in the x-direction; ∂f/∂y tells you the rate of change purely in the y-direction.

A linear example: f(w₁, w₂, w₀) = w₁x₁ + w₂x₂ + w₀

∂f/∂w₁ = x₁  ·  ∂f/∂w₂ = x₂  ·  ∂f/∂w₀ = 1

Gradients: partial derivatives collected into a vector

Collect every partial derivative of a function into one vector, and you get its gradient, written ∇f. If a function has n input variables, its gradient has n components — one per variable.

∇w̄ f(w̄) = [ ∂f/∂w₁, ∂f/∂w₂, …, ∂f/∂w₀ ]ᵗ
Terminology. For a single-variable function we call the rate of change a derivative. For a multivariable function we call the full vector of partial derivatives a gradient.

Geometric interpretation

For a single variable, the derivative was the slope of a tangent line. With several variables there's no single tangent line, but the gradient plays the same role: it's the vector that behaves most like a "slope" in many dimensions at once.

Magnitude

The length of the gradient vector gives the maximum rate of change of the function at that point.

Direction

The gradient always points in the direction of steepest ascent — the direction in which the function's value increases fastest.

Because the gradient points toward increasing values, reaching a minimum means moving in the opposite direction — the negative of the gradient.

For f(x, y) = x² + y² at the point (2, 1), the gradient is [4, 2]ᵗ — pointing away from the origin, where the function's minimum sits.

Visualising the gradient vector field

Computing the gradient at every point on a grid and drawing each as a small arrow produces a gradient field. For the bowl-shaped function f(x, y) = x² + y², every arrow points outward, away from the minimum at the origin — confirming that the gradient points toward increasing values. Flipping every arrow (taking the negative gradient) makes them all point inward, toward the minimum — exactly the direction gradient descent needs to travel.

The intuition of gradient descent

Gradient descent starts with an initial guess for where a function's minimum might be, then repeatedly nudges that guess in the direction the gradient says will reduce the function's value.

The three steps:
  1. Start with an initial guess, x⁽⁰⁾.
  2. Compute the derivative (or gradient) at that point.
  3. Update the guess using the gradient descent rule, and repeat.
x(1) = x(0) − η · d/dx f(x)

Here η ("eta") is the learning rate — how big a step to take in the gradient's direction. Subtracting the derivative automatically moves the guess the right way: a negative slope increases x, and a positive slope decreases x, both toward the minimum.

A learning rate that's too small crawls toward the minimum in tiny, slow steps; one that's too large can overshoot and oscillate past it. A well-chosen η converges quickly and steadily, with the step size naturally shrinking as the slope flattens near the minimum.

Generalising to n variables

Everything above extends directly to functions with many input variables — simply replace the single derivative with the full gradient vector, and update every variable at once:

w̄(t+1) = w̄(t) − η · ∇w̄ f(w̄(t))

The specific loss function being minimised changes from algorithm to algorithm, but the mechanism for optimising its parameters — subtract a learning-rate-scaled gradient, repeat — stays exactly the same.
