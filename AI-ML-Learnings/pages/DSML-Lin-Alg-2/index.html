From lines to hyperplanes

A single 2D line like w₁x₁ + w₂x₂ + w₀ = 0 can separate red and green points when there are two features. Add a third feature, and that same equation no longer applies — the data now lives in 3D, and separating it requires a plane: w₁x₁ + w₂x₂ + w₃x₃ = 0. This is called a 3D hyperplane, and the pattern continues into any number of dimensions.

Vectors

A vector carries both a magnitude and a direction. In code, it's simply a collection of numbers — a list, tuple, or array. Written mathematically, a vector is denoted with a bar (x̄) or an arrow (x⃗), and — by convention in ML and mathematics — is always represented as a column, not a row. A d-dimensional vector is written x̄ ∈ ℝᵏ ("x belongs to the set of all real numbers in d dimensions").

Magnitude and norm

The distance of a vector's tip from the origin is its magnitude (or length). By the Pythagorean theorem, for a 2D vector:

‖x̄‖ = √(x₁² + x₂²)   →   generalises to √(x₁² + x₂² + … + x_d²)

In the ML world, this same quantity is called the norm of the vector, written with double pipes: ‖x̄‖.

Euclidean vs. Manhattan distance

L2 norm — Euclidean distance

The straight-line ("as the crow flies") distance: ‖x‖₂ = √(x₁² + x₂² + … + x_d²). This is the default when no subscript is written.

L1 norm — Manhattan distance

The distance travelled along a grid of streets, like Manhattan's city blocks: ‖x‖₁ = |x₁| + |x₂| + … + |x_d|.

Matrix multiplication and the dot product

Two column vectors of the same shape can't be multiplied directly — matrix multiplication requires the number of columns in the first to match the number of rows in the second. Transposing one vector into a row solves this: multiplying a row vector (xᵗ) by a column vector (y) produces a single number. This is the dot product:

x̄ᵗy = x₁y₁ + x₂y₂ + … + x_d y_d
Multiplying two row vectors by mistake produces a full matrix, not a scalar — the convention of keeping vectors as columns is exactly what makes the dot product notation (x̄ᵗy) work.

Worked example: a loan-approval score

Given weights w̄ = [10, 4, 700] and features x̄ = [x₁, x₂, x₃], the score is w̄ᵗx̄ = 10x₁ + 4x₂ + 700x₃. "Learning," in a machine learning model, means finding the w̄ vector that produces the best decision boundary — nothing more exotic than that.

Angle between vectors

cos θ = x̄ᵗȲ / (‖x̄‖ · ‖ȷ̄‖)

The sign of cos θ splits the plane into two behaviors: positive from 0°–90° and 270°–360°, negative from 90°–270°. This sign test is exactly how a new point's halfspace — and therefore its predicted class — gets decided.

Unit vectors

A unit vector has direction but magnitude exactly 1 — found by dividing a vector by its own norm:

ŵ = w̄ / ‖w̄‖ = [ w₁/√(w₁²+w₂²), w₂/√(w₁²+w₂²) ]

Unit vectors isolate pure direction, stripped of scale — useful whenever only a vector's direction matters, not its length.

Vector projection

Given two vectors x and y, the projection of x onto y is the "shadow" x casts onto y — the length along y that x effectively reaches. Using trigonometry on the right triangle formed by x, its projection p, and the perpendicular connecting them:

‖p‖ = ‖x̄‖ cos θ = x̄ᵗȲ / ‖Ȳ‖

In other words, the length of the projection of x onto y is exactly the component of x pointing in y's direction.
