Today's Focus

So far, we have studied Bagging, where multiple models are trained independently and their predictions are combined to improve performance.

In this lecture, we will explore another powerful ensemble technique called Boosting. Unlike Bagging, Boosting builds models sequentially, where each new model focuses on correcting the mistakes made by the previous ones. We'll develop the intuition behind Boosting and understand why it often achieves higher predictive performance than a single model.

How Does Boosting Work for Classification?

Let us assume:

  • We have the data (xi, yi)
  • But our values of yi are 0 or 1.

Now, we have to predict the probability of yi being 0 or 1, i.e., pi.

Case 1: yi = 1

For model where xi = [0,1,3,1] and yi=1

  • Let's assume h0(x1) predicts 0.4

What will be the error here?
- error0 = 1 - 0.4 = 0.6
- Second model will fit the data on (xi, 0.6)
- Suppose h1(x) = 0.2

What will be the final model after stage 2?
- So, final model after second stage
- F1(x)=γ0h0(x)+y1h1(x) = 0.4 + 0.2 = 0.6

What will be the residual?
Residual will be yi−F1(x) = 1 - 0.6 = 0.4

We keep on fitting the models on the residual....

Case 2: yi = 0

Assume the same case,

For model where xi = [0,1,3,1] and yi=0

  • Let's assume h0(x1) predicts 0.4
What will be the residual after F0(x) or h0(x)?

Residual = yi−F0(x) = 0 - 0.4 = -0.4
Now, next model will fit on (xi, −0.4) and so on ..

We now know how Boosting works for both regression and classification. But remember the caution we raised earlier: if we keep adding stages, the training error keeps dropping toward zero. That sounds great, but it means the model could memorize the training data. So how do we control this? Let us look at the overfit-underfit tradeoff in Boosting and understand which knobs we can turn.

06

Overfitting-Underfitting Trade-off

How Can We Regularize the GBDT Model?

sklearn documentation: https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.GradientBoostingClassifier.html

1. M - The Number of Base Learners

What will happen if M increases?

As the number of base learners increases, it is more likely that the train error will go to 0.
Hence, the model will overfit.

As M increases, the model will overfit.

2. The Depth of Base Learners

What will happen if depth increases?
As depth increases, the model will overfit.

How?
Let's say we have deep DT for base learners, i.e., overfit models.
- In that case, within 4 or 5 models, we'll crazily overfit to noise.

Hence, we don't use deep DT as base learners.

With great power comes great risk

The biggest risk of GBDT is:

  • it can overfit easily if we are not careful

So, in order to avoid that, we introduce another level of regularization.

3. Shrinkage or Learning Rate (ν)

We add a regularization term ν to the model Fm(x) such that:

  • Fm(x)=Fm−1(x)+ν γmhm(x)

What will be the value of ν (nu)?
This 𝜈 always lies between 0 and 1.

What is ν doing intuitively?
Intuitively, ν is shrinking the impact of the mth model so that models don't overfit easily.

Think of it as an additional lever to control the overfit.

So, we can say that,

as ν increases, chances of model overfitting increases.

Note: We have the same 𝜈 for all models in GBDT.

Learning Rate vs Base Learners

Question: What should be done to M if ν is decreased to keep the performance same?

Number of base learners should be increased because as we are decreasing ν,
- we are restricting base learners contribution,
- due to which the error increases.

We use ν even when the γ is there to avoid overfit, as there are high chances of overfitting.

What Happens at Train and Test Time?

GBDT is a sequential model, hence it is slow to train.

14

How Can We Speed Up GBDT?

  • Row sampling and column sampling can speed up the model a little.
  • While building each base learner, we can apply parallelization, i.e., one sub-tree can be built on a core and the other sub-tree can be built on another core.
  • Even for building a single tree, we have to calculate entropy of many features; this can be parallelized.

We have covered how to make GBDT faster. One last important topic before we wrap up. Boosting learns from errors sequentially. So what happens when there is an outlier in the data, a data point with a very large error? Will Boosting keep trying to fix that one outlier and ignore everything else? Let us understand how outliers affect Boosting and what we can do about it."

Impact of Outliers

Question: Will outliers impact GBDT?

Outliers can impact GBDT.

  • Each model is fit on the residual of the previous model.
  • Outliers will have higher residual values.
  • So, gradient boosting will focus a large amount of its attention on reducing residual for these points.

Question: How to handle outliers?

  1. Remove outliers.
  2. Specialized or smart loss functions to handle outliers.

What changes can we make in the loss function so that the model be robust to outliers?

  • We can use Root mean squared error.
  • We can use absolute values of the error.
