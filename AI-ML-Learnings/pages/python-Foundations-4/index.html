Loops

What this post-read covers

Why loops are useful; for, range(), while, nested loops, break, continue, pass, common loop patterns, infinite loops, and two cumulative practice challenges.

01 · the idea

What if we need to repeat something?

Writing the same instruction five times works — but writing it 100 times is not a sensible way to program. A loop lets us write an instruction once and tell Python how or when to repeat it.

🔮 Before you reveal: how would you ask Python to print something 100 times without writing print() 100 times?

Think in plain English first: “Repeat this instruction.” That idea is the foundation of loops.

Mental modelStart → perform an action → decide whether to repeat → repeat or move on.
✅ TakeawayA loop executes the same block of code multiple times instead of making you write the same instruction repeatedly.

07 · while loops

Repeat while a condition is true

🔮 Trace it first: what is the first value printed? What is the last?
count = 1

while count <= 5:
    print(count)
    count += 1

1
2
3
4
5

The condition is checked before each iteration. After printing 5, count becomes 6, so 6 <= 5 is false and the loop ends.

Why does count += 1 matter?

🔮 Predict what happens if it is removed.

Infinite loop. If count stays 1, count <= 5 remains true forever.

count = 1
while count <= 5:
    print(count)
    # count never changes
⚠️ Don't run this versionThis snippet does not terminate. A while loop needs a path that eventually makes its condition false unless an intentional infinite loop is being created.
✅ TakeawayA while loop keeps running while its condition remains true. Always check how the condition can eventually become false.

09 · while in practice

Keep asking until the condition changes

password = ""

while password != "python":
    password = input("Enter the password: ")

print("Access granted!")

The program keeps asking while the password is incorrect. Once the user enters python, the condition becomes false and the loop stops.

10 · loop control

break, continue, and pass

🔮 break: how far does this loop actually get?
for i in range(1, 11):
    if i == 6:
        break
    print(i)

1
2
3
4
5

When i == 6, break immediately exits the entire loop.

🔮 continue: does 3 disappear, or does the loop stop?
for i in range(1, 6):
    if i == 3:
        continue
    print(i)

1
2
4
5

continue skips the rest of the current iteration and moves to the next one.

🔮 pass: is it the same as continue?
for i in range(5):
    if i == 3:
        pass
    else:
        print(i)

0
1
2
4

The output looks similar, but the mechanism is different. pass does nothing; it does not skip an iteration or terminate the loop. Here, 3 is absent because the print() is only in the else branch.

pass is useful as a placeholder when Python requires a statement but the implementation is not ready yet.

StatementEffect
breakExit the entire loop.
continueSkip the current iteration.
passDo nothing; continue normally.
✅ TakeawayThink in scope: break stops everything, continue skips one pass, and pass simply occupies a place in the code.

3. Counting matches

🔮 How many of these six numbers are even?
numbers = [2, 5, 8, 11, 14, 17]
count = 0

for number in numbers:
    if number % 2 == 0:
        count += 1

print(count)

3

Pattern: loop → check condition → if true, update result.

4. Finding a value

🔮 Why is break useful once 15 is found?
numbers = [4, 8, 12, 15, 20]
target = 15
found = False

for number in numbers:
    if number == target:
        found = True
        break

print(found)

True

Once the target is found, there is no need to keep searching.

5. Filtering

🔮 Which numbers will print?
numbers = [1, 2, 3, 4, 5, 6]

for number in numbers:
    if number % 2 != 0:
        continue
    print(number)

2
4
6

Odd numbers are skipped; even numbers reach print().

13 · mini project

Simple Number Analyzer

Build a program that asks for a number, prints every number from 1 up to it, and labels each number as even or odd.

n = int(input("Enter a number: "))

for i in range(1, n + 1):
    if i % 2 == 0:
        print(i, "- Even")
    else:
        print(i, "- Odd")
🔮 Why is the stop value n + 1, not n?

Because range() stops before its upper bound. To include n, the stop value must be n + 1.

✅ TakeawayThis combines input, variables, type casting, modulus, Boolean conditions, if/else, for, and range().
14 · mini challenge

Guess Until Correct

Create a program that repeatedly asks the user to enter a number until they enter 7.

number = 0

while number != 7:
    number = int(input("Guess the number: "))

print("Correct!")

Extension:

if number < 7:
    print("Too low!")
elif number > 7:
    print("Too high!")
🔮 Why is while appropriate here? When does the loop stop?

The number of guesses is unknown in advance, so the condition controls the repetition. The loop stops when number != 7 becomes false — when the user enters 7.

16 · debug clinic

Common loop problems

🔮 Debug 1: Why might this loop never end?
count = 1

while count <= 5:
    print(count)

Diagnosis: count never changes, so the condition stays true. Add a state update such as count += 1.

🔮 Debug 2: Why does this print 1, 2, 3 and then stop?
for i in range(1, 11):
    if i == 3:
        break
    print(i)

Diagnosis: break exits the entire loop. If the goal is to skip 3 and continue, use continue.

🔮 Debug 3: What would happen if the increment changes the wrong variable?
count = 1
total = 0

while count <= 5:
    total += count
    total += 1

Diagnosis: count never changes, so the loop condition never becomes false. The update must affect the variable controlling the condition.

Debug habitBefore changing code, predict what the loop is doing, trace the controlling variables, then test the smallest change that could fix it.
