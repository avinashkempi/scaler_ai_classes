Aggregate Functions

❝ An aggregate turns many numbers into one: a total, an average, a maximum. The axis decides which direction you collapse.

Key Calls

# No axis: single number for everything np.round(report.mean(), 1) np.float64(68.8)
# axis=0 → average per subject (down each column) np.round(report.mean(axis=0), 1) array([68.9, 68.1, 69.5])
# axis=1 → total per student (across each row) report.sum(axis=1) array([235, 135, 275, 104, 209, 258, 164, 272])
# argmax/argmin: WHO topped or scored lowest? report.argmax(axis=0) + 1 # +1: position → roll number array([3, 3, 8]) # Roll 3 topped Maths & Science, Roll 8 topped English
SQLreport.mean(axis=0) → SELECT AVG(maths), AVG(science), AVG(english)  ·  report.sum(axis=1) → SELECT maths + science + english AS total

⚠ Watch out: axis means the direction you collapse, not the direction of the answer. axis=0 removes the rows → one value per column. argmax with no axis returns a position in the flattened array — rarely what you want on a marksheet.

Fancy Indexing & Boolean Masking

❝ Fancy indexing is a list of positions. Boolean masking is a condition applied to every value at once.

Fancy Indexing in 2D

# Rolls 2 & 5 → rows 1 & 4 → then Maths & English columns report[[1, 4]][:, [0, 2]] array([[45, 52], [67, 70]])
⚠ report[[1,4], [0,2]] pairs them: gives array([45, 70]) — 2 cells, not a 2×2 block.

Boolean Masking + Row Masks

# Full-grid mask → flat 1D low_mask = report < 50 report[low_mask] array([45, 38, 34, 41, 29, 48])
# Row mask → keeps whole rows (shape 8,) low_maths = report[:, 0] < 50 report[low_maths] array([[45, 38, 52], [34, 41, 29]])
# np.any / np.all with axis=1 → one answer per student needs_help = np.any(report < 50, axis=1) np.arange(1,9)[needs_help] array([2, 4, 7])
SQLreport[report < 50] → WHERE mark < 50  ·  np.any(report < 35) → EXISTS (SELECT 1 WHERE mark < 35)

Sorting & argsort

❝ np.sort gives you the values in order. argsort gives you the positions — so whole rows can move together.

sort vs .sort vs argsort

# np.sort: returns sorted copy, original unchanged np.sort(maths_mid)[::-1][:3] # top 3 array([92, 91, 88])
# .sort(): modifies IN PLACE, returns None x = arr.sort() # ⚠ x is None — data gone!
# argsort: positions not values → reorder whole rows order = np.argsort(totals)[::-1] report[order] # rows stay intact

"Difference between np.sort and np.argsort?" — sort returns sorted values; argsort returns the positions that would sort them, which you then use to reorder other data like whole student rows.

Vectorization & np.vectorize()

❝ Vectorization means one operation for the whole array — no loop. np.vectorize() makes a Python if-else function array-compatible.

The Problem

def grade(mark): if mark >= 75: return "Distinction" elif mark >= 60: return "Merit" elif mark >= 35: return "Pass" else: return "Fail" grade(score) # whole array → ValueError # if expects ONE True/False, gets 24
# The fix: wrap it grade_all = np.vectorize(grade) grade_all(score) array([['Distinction', 'Distinction', 'Merit'], ['Pass', 'Fail', 'Pass'], ...])

05

Broadcasting

❝ Broadcasting lets a smaller array stretch to fit a bigger one. NumPy doesn't copy the data — it behaves as if the values were repeated.

Board Moderation (Case 1)

# +5 Maths, 0 Science, +2 English → row (3,) stretches down moderation = np.array([5, 0, 2]) # shape (3,) moderated = score + moderation # (8,3) + (3,)

Remedial Bonus (Case 2 — reshape needed)

# 8 per-student bonuses: needs shape (8,1) not (8,) remedial = np.array([0,3,0,4,0,0,1,0]) moderated + remedial # ⚠ ValueError! results = moderated + remedial.reshape(8,1) # ✓

Conditional Logic with np.where()

❝ np.where asks every value one question and picks one of two answers: value_if_true or value_if_false.

Three Uses

# 1. Replace a value: cap marks at 100 results = np.where(results > 100, 100, results)
# 2. Label every mark: Pass / Fail np.where(results >= 35, "Pass", "Fail")
# 3. Find positions (1 argument): WHERE are they? np.where(results[:, 0] < 35)[0] + 1 array([4, 7]) # Rolls 4 & 7 failed Maths

⚠ Two jobs, same name: With 3 arguments → new array of same shape. With 1 argument → tuple of positions. Always use [0] to get the array from the tuple.
SQLnp.where(results>=35,"Pass","Fail") → CASE WHEN mark >= 35 THEN 'Pass' ELSE 'Fail' END
07

np.select() — Multiple Conditions

❝ np.where picks between two outcomes. np.select checks a list of conditions in order and picks the first that matches.

Grade Bands — np.select vs np.vectorize

conditions = [results >= 75, results >= 60, results >= 35] choices = ["Distinction", "Merit", "Pass"] bands = np.select(conditions, choices, default="Fail")
ToolUse whenSpeed
np.where(c,a,b)Two outcomes (Pass/Fail)Fast ✓
np.select(conds,choices)3+ outcomes (grade bands)Fast ✓ (~12× faster than vectorize)
np.vectorize(func)Logic too complex for conditionsSlow (Python loop)

Quiz — Review Week Check

Four questions, one per core concept. All use the Greenfield High arrays.

Q1 · Which call gives each student's total, and what shape is the result?
report.shape # (8, 3)
✅ B is correct. A student is a row, so we add across each row: axis=1 collapses the 3 columns. 8 rows → shape (8,). A gives one total per subject. C gives one scalar for the whole class. D: aggregates drop the collapsed dimension — you get (8,) not (8,1).
Q2 · report has shape (8, 3). After report[report < 50], what is the shape of the result?
✅ B is correct. A full-grid mask (8×3 True/False) always returns only the matching values as a flat 1D array — the grid shape is lost. For D (keep whole rows), you need a row-shaped mask: report[report[:, 0] < 50].
Q3 · What shape does remedial need so this works?
moderated.shape # (8, 3)  remedial: 8 per-student bonuses
✅ C is correct. A 1D array always aligns to the last dimension (columns). (8,) would be treated as 8 subjects — a shape mismatch. (8, 1) is a column; broadcasting stretches it right across 3 columns, so each student's bonus is added to all 3 of their marks.
Q4 · Which statement about np.vectorize() is true?
✅ B is correct. np.vectorize wraps your function so it accepts arrays and returns an array of the same shape. Inside, it still calls your function once per value in Python — it saves typing, not time. For grade bands over large arrays, np.select is ~12× faster.
